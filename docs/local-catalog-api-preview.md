# Local Pokémon catalogue

The Admin → Catalog panel defaults to adding or updating every physical set published by TCGdex for the selected card language. Admins can instead enable the single-set option and choose one set. Each set and its card metadata are fetched and validated separately, then transactionally merged into a new snapshot that retains other synced sets and collection references. Bulk sync proceeds sequentially and reports set and card progress; if TCGdex lists a set but returns no cards, bulk sync reports and skips that set, then continues. Other failures stop the run while preserving completed sets for a safe retry. Metadata sync does not download artwork or build scanner indexes. The optional scan-index action starts after the sync run completes and includes only sets with card data.

Admins can enable or disable local Pokémon search and card lookups from the same panel; the persisted setting takes effect immediately without a restart. Local mode is strict: missing language snapshots/cards are not fetched from a provider. The legacy `POKEMON_LOCAL_CATALOG=1` environment variable seeds the persisted setting only when the database column is first added; subsequent changes belong in the Admin UI.

Authenticated `/api/sets?game=pokemon&lang=…` uses the active local set listing when a snapshot exists. If none exists for that language, it falls through to the configured provider so users can browse sets before syncing them. Local search still requires an active snapshot and reports a sync-required error when one is absent.
